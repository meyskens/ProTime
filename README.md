# ProTime Watchface for Pebble

Beste Reizigers, het is 16:26 en u bevind zich op de readme van de ProTime Watchface voor Pebble.
Een draagbare variant van de bekende ProRail stationsklok (bekend van NS). Voor u kompleet met verschillende achtergrondkleuren (vierkante Pebbles only), een keuze van secondewijzer mechanisme en speciaal voor u ook een datumweergave. Namens de fand van de Nederlandse Spoorwegen en het gehele team wens ik u een fijne reis met ProTime.

*This watchface was 100% coded while on NS trains and ProRail stations*

## Base

This watchface is based on [ModernSwiss](https://github.com/meyskens/ModernSwiss) which is a upgrade of original work by Johnny Lim's Mondaine watchface, forked by Leo Lin then updated by us and dutchified.
